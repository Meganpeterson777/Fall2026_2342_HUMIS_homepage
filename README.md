# Megan Peterson

## Working on the HUMIS website taught me a lot about the process of building and organizing a multi-page website. Throughout this project, I became more comfortable using WebStorm, HTML, CSS, and GitHub to create individual pages and connect them through navigation. I also learned how important it is to keep files, images, and stylesheets organized because even small issues with file names or links can affect how the website appears once it is published. One of the biggest challenges was figuring out how GitHub branches worked and making sure all of my pages were available on the final website. I think I benefited from this project because it gave me more hands-on experience with web design and helped me understand how much work goes into creating a website beyond just making it look good. I had to think about how users would move between pages, how the layout would stay consistent, and how the website would function outside of my own computer. It also helped me become more comfortable troubleshooting problems on my own instead of immediately knowing what to do. Even though some parts of the process were frustrating, I feel like I have a better understanding of how websites are built and published now. If I had to build a website like this again without having creative direction over it, I would spend more time at the beginning understanding the existing design, layout, and expectations before starting to build the pages. I would also create a clearer plan for organizing my files and setting up my GitHub branches so I would not run into as many issues later. Since I was not able to make all of the creative decisions myself, I had to focus more on consistency, following the existing design, and making sure everything worked properly. Overall, this project taught me that web design is not always about having complete creative freedom, but also about being able to work within an existing system and make it function well.
